# Настройка HTTPS для локальной разработки

После обновления конфигурации приложение теперь работает через **HTTPS**.

## ⚠️ ВАЖНО: Обновите настройки

### 1. Обновите файл `web/.env`

```env
# API Configuration
VITE_API_URL=/api

# Yandex ID Configuration
VITE_YANDEX_CLIENT_ID=44d799edfaaa407eb79fb0eafed36a44
VITE_YANDEX_REDIRECT_URI=https://localhost:5173/
```

**ИЗМЕНЕНО:** `http://` → `https://`

###  2. Обновите Redirect URI в консоли Yandex OAuth

1. Откройте https://oauth.yandex.ru/
2. Выберите ваше приложение
3. В разделе **"Платформы"** → **"Веб-сервисы"**
4. Измените Callback URI с `http://localhost:5173/` на:
   ```
   https://localhost:5173/
   ```
5. Сохраните изменения

### 3. Перезапустите dev-сервер

```bash
# Остановите текущий сервер (Ctrl+C)
# Затем запустите снова:
npm run dev
```

### 4. Откройте приложение через HTTPS

Теперь приложение доступно по адресу: **https://localhost:5173/**

⚠️ **Предупреждение о сертификате:**

При первом открытии браузер покажет предупреждение о небезопасном сертификате. Это нормально для локальной разработки с само подписанным сертификатом.

**Как обойти предупреждение:**

#### Chrome/Edge:
1. Нажмите **"Дополнительно"** (Advanced)
2. Нажмите **"Перейти на сайт localhost (небезопасно)"**

#### Firefox:
1. Нажмите **"Дополнительно"**
2. Нажмите **"Принять риск и продолжить"**

## 🎯 Почему HTTPS?

Yandex ID требует HTTPS для виджета мгновенного входа по соображениям безопасности:

- Content Security Policy (CSP) Яндекса требует `https://` для `frame-ancestors`
- Это стандартная практика OAuth и защиты данных пользователей

## 🔍 Проверка

После перезапуска откройте консоль браузера (F12) и проверьте:

```javascript
console.log('Current origin:', window.location.origin);
// Должно вывести: https://localhost:5173
```

Виджет Yandex ID должен теперь успешно загружаться!
