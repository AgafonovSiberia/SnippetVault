# SnippetVault Frontend

Современный веб-интерфейс для приложения SnippetVault, построенный на React с использованием Material UI.

## 🚀 Технологии

- **React 19** - современная библиотека для создания UI
- **TypeScript** - статическая типизация
- **Vite** - быстрый сборщик и dev-сервер
- **Material UI (MUI)** - компонентная библиотека Material Design
- **React Router** - маршрутизация
- **Axios** - HTTP клиент
- **Emotion** - CSS-in-JS решение для стилизации

## 🛠️ Установка и запуск

### Предварительные требования

- Node.js >= 18.x
- npm >= 9.x

### Шаги установки

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
   
   Отредактируйте `.env` и укажите:
   - `VITE_YANDEX_CLIENT_ID` - Client ID вашего приложения в Yandex OAuth
   - `VITE_YANDEX_REDIRECT_URI` - URI для редиректа после авторизации

3. **Запустите dev-сервер:**
   ```bash
   npm run dev
   ```

   Приложение будет доступно по адресу: http://localhost:5173

4. **Сборка для production:**
   ```bash
   npm run build
   ```

   Собранные файлы будут в папке `dist/`

## 🔐 Настройка Yandex ID

1. Зарегистрируйте приложение на [Yandex OAuth](https://oauth.yandex.ru/)
2. В настройках приложения укажите:
   - **Redirect URI**: `http://localhost:5173/` (для разработки)
   - **Platforms**: Web
3. Скопируйте **Client ID** и добавьте его в `.env` файл

## 🏗️ Архитектура

### Компоненты

Компоненты организованы по принципу **Atomic Design**:
- `components/common/` - базовые переиспользуемые компоненты
- `components/auth/` - компоненты, специфичные для авторизации

### Сервисы

Все взаимодействие с API инкапсулировано в сервисах:
- `ApiClient` - базовый HTTP клиент с перехватчиками
- `AuthService` - сервис авторизации

### Хуки

Кастомные React хуки для управления состоянием:
- `useAuth` - управление состоянием авторизации

### Роутинг

Приложение использует защищенные и публичные маршруты:
- **Публичные** - доступны без авторизации (страница логина)
- **Защищенные** - требуют авторизации (дашборд)

## 🎨 Стилизация

### Тема

Приложение использует кастомную темную тему Material UI:
- Темная цветовая схема
- Кастомная палитра
- Модифицированные компоненты (Button, Card, TextField)
- Шрифт Inter

### Дизайн-система

- Градиенты и glassmorphism эффекты
- Плавные анимации и transitions
- Адаптивная сетка
- Кастомные scrollbar

## 🔒 Безопасность

- Access токены хранятся в `localStorage`
- Refresh токены в HTTP-only cookies
- Автоматическое обновление токенов при истечении
- CSRF защита через `SameSite` cookies

## 🌐 API Интеграция

API клиент настроен на работу с backend:
- Базовый URL: `/api` (проксируется через Vite)
- Автоматическая обработка авторизации
- Retry логика для обновления токенов
- Централизованная обработка ошибок
